# 💰 Personal Finance Tracker

A modern and responsive **Personal Finance Tracker** built using **HTML, CSS, and JavaScript**. The application helps users manage their daily income and expenses, visualize monthly spending trends, and track their financial balance through an intuitive user interface.

---

## ✨ Features

- ➕ Add new transactions
- ✏️ Edit existing transactions
- 🗑️ Delete transactions
- 💵 Track Income & Expenses
- 📊 Real-time Balance Calculation
- 🔍 Search Transactions
- 🏷️ Filter by Category
- 📈 Monthly Expense & Income Chart
- 🌙 Dark / Light Mode
- 💾 Local Storage Support
- 📱 Fully Responsive Design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Chart.js
- Local Storage API

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/Personal-Finance-Tracker.git
```

Open the project

```bash
cd Personal-Finance-Tracker
```

Run the application

```
Open index.html in your browser
```

## 📖 How to Use

1. Add your income or expense.
2. Enter the amount and category.
3. Save the transaction.
4. View updated balance instantly.
5. Search or filter transactions.
6. Analyze monthly spending using the chart.
7. Switch between Light and Dark mode.
8. Refresh the page—your data remains saved using Local Storage.
